NOCTURNE — Projet HTML / CSS / JavaScript

Lancement :
1. Décompresse le dossier.
2. Ouvre index.html dans Chrome, Firefox ou Edge.
3. Pour modifier le contenu, édite index.html et style.css.

Personnages :
Ajoute les portraits dans assets/ sous les noms :
personnage-1.jpg, personnage-2.jpg, personnage-3.jpg

Les animations GSAP/ScrollTrigger et les polices Google nécessitent une connexion Internet.
Le site garde une présentation de base si GSAP n'est pas chargé.

À personnaliser ensuite :
- Noms et surnoms dans les lignes du roster.
- Citations et pouvoirs dans les fiches.
- Photos de chaque personnage.
- Couleurs et textes selon votre univers.
